# MealHQ social assets

**Canonical mark for social:** [`../mealhq-icon-1024.png`](../mealhq-icon-1024.png)  
(M + route in teal ring — same icon used on the Facebook / Instagram Page profile.)

Do **not** use `mealhq-mark.png` (bowl split mark) for Page profile or posts.

## Layout

```
social/
  page/                        ← Page profile, cover (not posts)
  post-01-live/                ← first feed post
  reel-01-first-impression/    ← first Reel / video (~19s)
  post-02-…/                   ← future posts (one folder each)
```

Content + captions: [`docs/social-content/`](../../../docs/social-content/) — matching `post-NN-slug/` / `reel-NN-slug/` folders.

| Path | Use |
|------|-----|
| `page/mealhq-profile-1024.png` | FB + IG profile (copy of brand icon) |
| `page/mealhq-fb-cover-1640x924.png` | Facebook cover |
| `page/mealhq-ig-landscape-1080x566.png` | Optional IG landscape |
